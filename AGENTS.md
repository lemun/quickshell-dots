# Personal Quickshell fork

When Shai requests bar tweaks or ricing, save both the implementation and exact
portable preferences in this repo. profiles/shai is the default restored by
omarchy-dotfiles/setup quickshell on another installation. Commit and push
validated changes by default unless the user requests local only work.
Keep quickshell-dots standalone; do not vendor it into omarchy-dotfiles.

Before changing/restarting the live bar or otherwise interrupting the active
session, announce the exact action and likely effect and get explicit approval.
Repository edits and isolated headless tests do not need a bar restart.
Never copy credentials, pairing keys, runtime caches, or machine identifiers.
Only the explicitly supported preference files belong in profiles/shai.
